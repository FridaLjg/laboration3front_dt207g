Om

Syftet med denna webbplats är att presentera och hantera arbetserfarenheter via en egenutvecklad webbtjänst. Man kan på startsidan se sina regristrerade arbetserfarenheter. På undersidan "Lägg till arbetserfarenhet" kan man lägga till nya arbetserfarenheter genom ett formulär. Kommunikation mellan webbplatsen och webbtjänsten sker med hjälp av Fetch API och data skickas och hämtas i JSON-format.

Databasserver

För lagring av data används NoSQL databasservern MongoDB tillsammans med Mongoose för schemahantering. Databasen innehåller information om arbetserfarenheter med följande fält:
Arbetsgivare (companyname)
Arbetsroll (jobtitle)
Plats (location)
Arbetsbeskrivning (description)
Mongoose används för att definiera databasens struktur och för att validera inkommande data innan den sparas.

Slutsatser

Genom denna uppgift har jag lärt mig hur man skapar en webbtjänst med Express och MongoDB. En skillnad jag märkte med att arbeta med MongoDB jämfört med MySQL är att i MongoDB skapas ett unikt id automatiskt för varje objekt. Detta är alltså inget jag behöver lägga till manuellt. MongoDb lade med andra ord till detta id:t fastän jag inte har definierat det i schemat.
En fördel jag upptäckte under arbetet med denna laboration var att det var lätt att lägga till nya fält i schemat. Då jag använde en del av arbetet från laboration 2, upptäckte jag att det saknades ett fält i schemat eftersom id var något som skapades automatiskt. Då lade jag till fältet "description", vilket var smidigt. Jag valde att inte göra detta fält obligatoriskt, för att exprimentera hur valideringen fungerar i Mongoose (då de andra fälten är obligatoriska).
